# Multi Repair Booking Platform

Multi Repair Booking Platform is a Java-based web application developed using Spring MVC architecture.  
The main purpose of this project is to provide an online platform where customers can easily book different types of repair services such as mobile repair, laptop repair, car repair, and cycle repair from a single system.

This project was created to understand how real-world service booking applications work, especially focusing on backend development concepts like authentication, CRUD operations, session handling, database connectivity, and role-based access management.

---

## Project Objective

The objective of this project is to simplify the repair booking process between customers and service providers.

Traditionally, customers need to physically visit service centers to register repair requests.  
This platform digitalizes the process by allowing users to:

- Register and login
- Book repair services online
- Track repair status
- View their bookings
- Communicate service requests efficiently

At the same time, administrators can manage customer bookings through a dedicated admin dashboard.

## Project Workflow

1. User registers into the system.
2. User logs in using email and password.
3. User submits a repair booking request.
4. Booking details are stored in MySQL database.
5. Admin logs into admin dashboard.
6. Admin views all customer repair requests.
7. Admin updates booking status.
8. User can track updated repair status from "My Bookings" section.
